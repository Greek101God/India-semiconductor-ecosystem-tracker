# India Semiconductor Ecosystem Tracker
  
  A self-directed research project mapping India's semiconductor ecosystem — 
  DRDO/ISRO R&D labs, DLI-linked design startups, and current policy — 
  built as a sample exercise for an EDA sales territory role.
  
  ## Contents
  - Dashboard: city/focus-area breakdowns with charts
  - DRDO Labs & ISRO Centres
  - DLI Scheme Startups
  - Policy Tracker
  - Territory Notes (business takeaways)
  - Methodology & Sources
  
  Compiled from public sources (PIB, ISM.gov.in, Inc42, industry press) — July 2026.
